# City Information Management System
## :rocket: Introduction
This is a web-based system used to manage the information withn a certain city or municipality. This covers the information of the citizen, requesting/applying for certain documents, reporting cases and many more.
It's purpose is to create a seamless transaction between the local government unit to the citizens of the area. It also embraces the future by integrating the techonlogy to day by day transactions and monitoring
of the area.
